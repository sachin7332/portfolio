02  ·  Nokia  ·  April 2026 — Present

Telemetry for the Nokia 7705 SAR-HM

The SAR-HM SNMP collector is a lightweight telemetry service for Nokia 7705 SAR-HM devices. It polls SNMPv2c OIDs on a steady cycle, turns raw MIB counters into structured CDM-compliant KPIs, and publishes that JSON to MQTT.

The CDM KPI engine consumes those topics and stores the series in InfluxDB. Operators then watch the network live in Nextspace.

  • Python
  • asyncio
  • SNMP
  • MQTT
  • Redis
  • InfluxDB
  • Docker
  • Kubernetes
  • Microsoft Azure
  1. Designed modular KPI builders in Python asyncio. Redis keeps the previous sample so throughput and packet loss are deltas, and the poll stays stable at 10–12 seconds.
  2. Shipped an MQTT publisher with QoS 1, TLS, and automatic reconnect, so a dropped broker does not silently end the stream.
  3. Packaged the collector as a multi-stage Docker image with environment-based configuration, and ran the same build from development through production on Kubernetes.
  4. Gave live demos to Nokia stakeholders: an MQTT subscription, InfluxDB queries, and the collector’s own performance, on one screen.
